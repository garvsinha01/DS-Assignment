Student Performance Record Management System-

Part 1 - Write a C++ program to store the Roll Numbers of 5 students in an array and display the stored Roll Numbers.

Part 2 - Write a C++ program to search for a particular student Roll Number from an array of 5 student Roll Numbers using Linear Search.

Part 3 - Write a C++ program to store the Roll Numbers of 5 students in an array, display all the stored Roll Numbers, and search for a particular Roll Number using Linear Search. Display whether the Roll Number is found or not.
