# DS-Assignment
1. Smart Library Book Management System-

   Part 1 – Store and Display Book IDs: Write a C++ program to store the IDs of 3                    library books and display all the book IDs entered by the user.

   Part 2 – Search for a Book: Write a C++ program to store the IDs of 5 library books               in an array and search for a given Book ID. Display “Book Found” if the ID               is present; otherwise, display “Book Not Found”.

   Part 3 – Sort Book IDs: Write a C++ program to store the IDs of 5 library books in an             array and arrange the Book IDs in ascending order using a simple sorting                 technique.

   Part 4 – Simple Library Menu Write a menu-driven C++ program for a simple                         library system that allows the user to add a Book ID, display all Book IDs,              search for a Book ID, display all Book IDs, search for a Book ID, and exit               the program.


2. Student Performance & Ranking Management System-

   Part 1 - Write a C++ program to store the Roll Numbers of 5 students and display all              the Roll Numbers entered by the user.

   Part 2 - Write a C++ program to store the Roll Numbers of 5 students in an array and              search for a given Roll Number. Display “Student Found” if the Roll Number               is present; otherwise, display “Student Not Found”.

   Part 3 - Write a C++ program to store the marks of 5 students in an array and arrange             the marks in descending order to display the students from highest marks to              lowest marks.

   Part4 - Write a menu-driven C++ program for a simple student management system that              allows the user to add a student's Roll Number and Marks, display all student            records, search for a student using Roll Number, and exit the program.
