Smart Restaurant Order Management System-

Part 1 - Write a C++ program to store 5 customer order numbers in a Queue and process the orders in the same order in which they were received.

Part2 - Write a C++ program to store 5 cancelled order numbers in a Stack and display the cancelled orders starting from the most recently cancelled order.

Part 3 - Write a C++ program using recursion to display a restaurant menu repeatedly and allow the user to select an option until the user chooses Exit.
