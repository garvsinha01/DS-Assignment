## 4. Smart Customer Service & Call Management System:-
A customer support center requires a system to efficiently manage customer service requests.
Incoming customer calls should be processed in the order they are received using a Queue, while urgent customer requests should be handled using a Priority Queue.
The system should maintain a history of recently resolved requests using a Stack, allowing support staff to review the latest interactions.
Additionally, an automated Interactive Voice Response (IVR) system should guide customers through multiple support options using recursion.
Students should implement appropriate Stack and Queue operations to simulate real-world customer service management.
