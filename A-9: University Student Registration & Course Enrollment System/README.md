University Student Registration & Course Enrollment System

A university requires a system to efficiently manage student registrations and course enrollments.

The system should allow administrators to register new students, update student information, enroll students in courses, withdraw students from courses, and remove student records when required. Since student registrations and enrollments change frequently, the records should be maintained using Linked Lists to support dynamic insertion and deletion. Each student should be assigned a unique Roll Number, enabling quick retrieval of student information using a Hash Table. If multiple Roll Numbers generate the same hash value, the system should implement suitable collision resolution techniques, such as Chaining or Open Addressing, to ensure efficient data retrieval.
