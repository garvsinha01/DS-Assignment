Student Performance & Ranking Management System-

Part 1 - Write a C++ program to store the Roll Numbers of 5 students and display all the Roll Numbers entered by the user.

Part 2 - Write a C++ program to store the Roll Numbers of 5 students in an array and search for a given Roll Number. Display “Student Found” if the Roll Number is present; otherwise, display “Student Not Found”.

Part 3 - Write a C++ program to store the marks of 5 students in an array and arrange the marks in descending order to display the students from highest marks to lowest marks.

Part4 - Write a menu-driven C++ program for a simple student management system that allows the user to add a student's Roll Number and Marks, display all student records, search for a student using Roll Number, and exit the program.
