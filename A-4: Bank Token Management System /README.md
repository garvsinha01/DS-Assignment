Bank Token Management System-

Part1 - Write a C++ program to store 5 customer token numbers in a Queue and serve the customers in the same order in which they received their tokens

Part2 - Write a C++ program to store 5 recently served customer token numbers in a Stack and display the service history starting from the most recently served customer.

Part 3 - Write a menu-driven C++ program for a simple bank token system that allows the user to issue a token, display all tokens, serve a customer, and exit the program.
